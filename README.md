# coc-dice-calc

クトゥルフ神話TRPG（CoC）7版のボーナスダイス／ペナルティダイスによる技能値補正を計算するWebツールです。

## 概要

CoC 7版ではボーナス／ペナルティダイスにより十の位ダイスが複数振られ、最も有利（または不利）な値が採用されます。このツールは、その仕組みによる成功確率の変動を計算し、6版互換の「技能値への補正値」として出力します。

## 機能

- **補正値の算出**: ボーナス／ペナルティダイスによる成功確率の変動を、技能値への整数補正として表示
- **CCBコマンドのコピー**: 補正後の技能値を用いた `CCB<=` コマンドをワンクリックでコピー
- **7版参考データ**: レギュラー／ハード／イクストリーム成功率、クリティカル・ファンブル確率を表示

## 計算ロジック

1. 一の位（0〜9）ごとに、十の位ダイスを `|netDice| + 1` 個振った場合の成功確率を算出
2. 全一の位の確率を合算して期待成功率を求める
3. `期待成功率(%) − 技能値` の差分（デルタ）を小数点以下切り捨てで補正値とする
4. 補正後の技能値は 1〜99 にクランプされる

## 使い方

1. `index.html` をブラウザで開く
2. 技能値（1〜99）を入力
3. ボーナス／ペナルティダイスの数を設定
4. 表示された補正値・CCBコマンドを利用する
